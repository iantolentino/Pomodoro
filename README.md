# ⏱️ Pomodoro Timer Web App

This is a clean and responsive Pomodoro Timer web application designed to boost productivity by implementing the popular Pomodoro Technique. It allows users to focus on tasks in timed intervals, track their progress, and manage task history.

---

## 🚀 Features

- Start, pause, and reset the Pomodoro timer  
- Adjust the timer duration with `+` and `-` buttons  
- Enter and track tasks  
- Task history with a reset option  
- Pomodoro session counter and total time analytics  
- Break time modal popup  
- Fully responsive layout with minimal design

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- Font Awesome Icons

## 🧑‍💻 Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/pomodoro-timer.git
   cd pomodoro-timer
   ```

2. Open `index.html` in your browser:
   ```bash
   start index.html  # Windows
   # or
   open index.html   # macOS
   ```

3. Click **Start** to begin the Pomodoro session, enter tasks, and track your focus time!
